قبل البدء

حالة ملفات التثبيت حاليًاإعدادات بناء ملفات التثبيت لنظامي macOS وWindows مكتملة، ومعها سير عمل على GitHub Actions يبنيها على أجهزة macOS وWindows حقيقية. لكن هذه الملفات لم تُبنَ بعد ولم تُختبر، لأن التطوير جرى في بيئة Linux، ولا يوجد حتى الآن رابط تنزيل جاهز لها. للحصول عليها اتبع الفصل الخامس «الحصول على ملفات التثبيت»، ثم عُد إلى خطوات التثبيت في الفصلين الثاني والثالث.

اعرف نوع جهازك

على macOS

  1. افتح قائمة Apple ثم اختر حول هذا الـ Mac.
  2. إذا ظهر سطر الشريحة (Chip) باسم مثل Apple M1 أو M2 أو M3 فجهازك Apple Silicon.
  3. إذا ظهر سطر المعالج (Processor) باسم Intel فجهازك Intel.

على Windows

  1. افتح الإعدادات ← النظام ← حول.
  2. انظر إلى نوع النظام: يجب أن يكون «نظام تشغيل 64 بت، معالج يستند إلى x64».

اختر الملف المناسب

اسم الملفلمن هو

التثبيت على macOS

خطوات التثبيت

  1. انقر نقرًا مزدوجًا على ملف .dmg المناسب لجهازك، فتُفتح نافذة فيها أيقونة التطبيق ومجلد Applications.
  2. اسحب أيقونة SmartText AI وأفلتها على مجلد Applications.
  3. أغلق النافذة، ثم أخرج القرص الافتراضي من Finder بالنقر على زر الإخراج بجوار اسمه.
  4. افتح التطبيق من مجلد التطبيقات أو من Launchpad.

إذا منع macOS فتح التطبيق

النسخ غير الموقّعة وغير الموثّقة من Apple يمنعها نظام Gatekeeper عند فتحها أول مرة، برسالة مثل «لا يمكن فتح SmartText AI لأنه لا يمكن التحقق من المطوّر». جرّب إحدى الطرق الآتية بالترتيب:

  1. في مجلد التطبيقات انقر بزر الفأرة الأيمن (أو Control مع النقر) على التطبيق، واختر فتح، ثم فتح مرة أخرى في النافذة التي تظهر.
  2. أو افتح إعدادات النظام ← الخصوصية والأمان، ومرّر إلى الأسفل، واضغط فتح على أي حال بجوار اسم التطبيق.
  3. إذا ظهرت رسالة «التطبيق تالف ولا يمكن فتحه»، فافتح تطبيق Terminal ونفّذ الأمر الآتي، ثم افتح التطبيق من جديد:
xattr -dr com.apple.quarantine "/Applications/SmartText AI.app"

هذه التحذيرات لا تظهر في النسخ الموقّعة بشهادة Developer ID والموثّقة من Apple.

إذن سلسلة المفاتيح

عند حفظ مفتاح API لأول مرة قد يسألك macOS عن السماح لـ SmartText AI باستخدام سلسلة المفاتيح. أدخل كلمة مرور جهازك واختر السماح دائمًا، حتى لا يتكرر السؤال عند كل طلب.

التحديث إلى إصدار أحدث

أغلق التطبيق، ثم ثبّت ملف .dmg الجديد بالطريقة نفسها، واختر استبدال عندما يسألك Finder. تبقى إعداداتك وسجلك ومفاتيحك كما هي.

إزالة التطبيق

  1. اسحب SmartText AI من مجلد التطبيقات إلى سلة المهملات.
  2. لحذف بياناتك المحلية أيضًا (الإعدادات والسجل والمحادثات والصور)، احذف المجلد الآتي من Finder عبر قائمة انتقال ← الانتقال إلى المجلد:
~/Library/Application Support/com.ismaielalmarie.smarttextai
  1. لحذف مفاتيح API المحفوظة: احذفها من داخل التطبيق قبل إزالته (الإعدادات ← مزوّدو الذكاء الاصطناعي ← إزالة المفتاح)، أو افتح تطبيق Keychain Access وابحث عن com.ismaielalmarie.smarttextai واحذف العناصر الظاهرة.

التثبيت على Windows

التثبيت بالمثبّت (setup.exe)

  1. انقر نقرًا مزدوجًا على SmartText-AI_1.0.0_x64-setup.exe.
  2. اختر لغة المثبّت: العربية أو English.
  3. اتبع خطوات المعالج واضغط تثبيت. يُثبَّت التطبيق للمستخدم الحالي، فلا يحتاج عادةً إلى صلاحيات المسؤول.
  4. إذا لم يكن WebView2 مثبّتًا، ينزّله المثبّت ويثبّته تلقائيًا؛ لذا تأكد من اتصالك بالإنترنت في هذه الخطوة.
  5. شغّل التطبيق من قائمة ابدأ أو من اختصار سطح المكتب.

التثبيت بحزمة MSI

حزمة SmartText-AI_1.0.0_x64_en-US.msi مخصّصة للنشر في المؤسسات عبر أدوات مثل Group Policy أو Intune. واجهة مثبّتها بالإنجليزية فقط، أما التطبيق نفسه فيدعم العربية كاملة. ويمكن تثبيتها بصمت من سطر الأوامر:

msiexec /i "SmartText-AI_1.0.0_x64_en-US.msi" /qn

إذا ظهر تحذير SmartScreen

قد تظهر رسالة «Windows protected your PC» عند تشغيل مثبّت غير موقّع رقميًا. اضغط More info (مزيد من المعلومات)، ثم Run anyway (التشغيل على أي حال). التوقيع الرقمي للمثبّت يزيل هذا التحذير تدريجيًا مع بناء السمعة لدى Microsoft.

التحديث إلى إصدار أحدث

أغلق التطبيق، ثم شغّل مثبّت الإصدار الجديد؛ فيستبدل الإصدار القديم مع الإبقاء على إعداداتك وسجلك ومفاتيحك.

إزالة التطبيق

  1. افتح الإعدادات ← التطبيقات ← التطبيقات المثبّتة، وابحث عن SmartText AI، ثم اختر إلغاء التثبيت.
  2. لحذف بياناتك المحلية أيضًا، الصق المسار الآتي في شريط عنوان مستكشف الملفات واحذف المجلد:
%APPDATA%\com.ismaielalmarie.smarttextai
  1. لحذف مفاتيح API: احذفها من داخل التطبيق قبل إزالته، أو افتح إدارة بيانات الاعتماد (Credential Manager) ← بيانات اعتماد Windows، واحذف العناصر التي تحمل الاسم com.ismaielalmarie.smarttextai.

التشغيل الأول

تحويل الواجهة إلى العربية

تُفتح لوحة التحكم مباشرة بعد التثبيت، والواجهة بالإنجليزية افتراضيًا. افتح Settings من الشريط الجانبي، ثم من قسم General اختر العربية من قائمة Interface language، فتنقلب الواجهة إلى العربية من اليمين إلى اليسار فورًا.

ربط مزوّد الذكاء الاصطناعي

  1. افتح الإعدادات ← مزوّدو الذكاء الاصطناعي، واختر المزوّد: OpenAI أو Anthropic أو خادم متوافق مع OpenAI.
  2. الصق مفتاح API في بطاقة المزوّد واضغط حفظ المفتاح. يُحفظ المفتاح في سلسلة مفاتيح النظام ولا يُعرض مرة أخرى.
  3. اضغط اختبار الاتصال وتأكد من ظهور رسالة «تم الاتصال».
  4. اختر النموذج من خانة نموذج النصوص، أو اضغط تحميل النماذج لجلب القائمة من حسابك.

بعد ذلك تصبح كل الميزات جاهزة. وللتفاصيل الكاملة عن استخدام كل قسم راجع دليل استخدام SmartText AI.

الحصول على ملفات التثبيت

لا يمكن بناء ملفات macOS وWindows إلا على أجهزة بهذين النظامين. أسهل طريقة هي GitHub Actions، فهو يبنيها مجانًا على أجهزة Mac وWindows سحابية دون أن تحتاج إلى أي منهما.

الطريقة الأولى: GitHub Actions (موصى بها)

  1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه شيفرة المشروع (ملف smarttext-ai-source.zip).
  2. افتح تبويب Actions في المستودع، واختر سير العمل Release builds.
  3. اضغط Run workflow، واكتب في خانة release_tag رقم الإصدار، مثل v1.0.0، ثم اضغط زر التشغيل الأخضر.
  4. انتظر انتهاء المهام الثلاث: macOS (Apple Silicon)، وmacOS (Intel)، وWindows x64. يستغرق ذلك عادةً بين 15 و30 دقيقة.
  5. افتح صفحة Releases في المستودع؛ ستجد إصدارًا جديدًا عليه ملفات التثبيت الثلاثة، ورابطه دائم ويمكنك مشاركته مع المستخدمين.
  6. إذا تركت خانة release_tag فارغة، فلن يُنشأ إصدار، وتجد الملفات في قسم Artifacts أسفل صفحة التشغيل.
التوقيع الرقمي (اختياري)بدون توقيع تعمل الملفات، لكنها تُظهر تحذيرات Gatekeeper وSmartScreen الموضّحة في الفصلين الثاني والثالث. لتوقيع نسخ macOS وتوثيقها أضف شهادة Apple Developer ID وبياناتها إلى أسرار المستودع (Secrets) كما يشرح ملف INSTALL_MACOS.md. وتوقيع Windows يحتاج إلى شهادة توقيع برمجيات، والتفاصيل في INSTALL_WINDOWS.md.

الطريقة الثانية: البناء على جهازك

على Mac

ثبّت أدوات Xcode للأوامر وRust وNode.js 22، ثم نفّذ داخل مجلد المشروع:

xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm ci
npm run tauri build -- --target aarch64-apple-darwin     # Apple Silicon
npm run tauri build -- --target x86_64-apple-darwin      # Intel
npm run tauri build -- --target universal-apple-darwin   # one app for both

ستجد ملف .dmg في المجلد src-tauri/target/<target>/release/bundle/dmg/.

على Windows

ثبّت Microsoft C++ Build Tools (حزمة «Desktop development with C++»)، ثم نفّذ في PowerShell:

winget install --id Rustlang.Rustup
rustup default stable-msvc
winget install OpenJS.NodeJS.LTS
npm ci
npm run tauri build

ستجد الملفين في src-tauri\target\release\bundle\nsis\ وsrc-tauri\target\release\bundle\msi\.
